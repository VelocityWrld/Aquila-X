# Aquila-X Research and References

## Scope

This document records the evidence status of the Aquila-X concept. The repository currently contains supplied project notes and an owner-provided documentation brief. It is not a literature review, certification dossier, supplier comparison, or new research direction.

## Primary source

The primary technical source is [`archive/original-documents/Aquila-X-Complete-Notes.md`](../archive/original-documents/Aquila-X-Complete-Notes.md). The public archive copy is a curated technical derivative of the owner-supplied source, preserving the technical content needed to explain the design while excluding non-technical planning material.

The owner-provided [documentation agent brief](../README.md) defines the transformation rules used in this repository: preserve meaning and reasoning, distinguish proposed from implemented, retain uncertainty, identify contradictions, avoid invention, and do not add external research until explicitly requested.

## Evidence status

The presence of a component name or capability in the source does not establish that it has been selected, procured, integrated, legally approved, or tested. In particular, the source does not provide evidence for a completed airframe, validated flight time, validated noise reduction, validated obstacle avoidance, implemented facial recognition, implemented swarm compatibility, implemented satellite fallback, or implemented secure deletion.

The source contains quantitative statements such as 30Ah, 30–60Ah, 30Ah-plus, 30–60W, 10–20 minutes, 120–200 minutes, 60% charging in 20–30 minutes, 0.7 Mach tip speed, and 3000–5000KV motors. These remain source-stated estimates or configuration statements. They are not test results.

## Contradictions and unresolved source terms

The source gives different battery and motor descriptions for prototype, advanced, and quiet-flight discussions. The documentation retains these as configuration-specific statements rather than silently selecting a final design.

The source uses “NCAA” when discussing Nigeria Civil Aviation Authority certification. This terminology is preserved as a source note and requires verification before it is used in a compliance claim.

The source also uses “RF interception,” “radio interceptor,” “self-wipe,” “radar-absorbent coating,” “facial recognition,” and “swarm compatibility.” These terms are recorded as proposed or conceptual capabilities and require separate legal, privacy, security, and engineering review.

## Future evidence needs

No new research direction is created here. If the project owner later requests research, evidence should be added for selected components, battery and propulsion integration, acoustics and vibration, thermal performance, navigation reliability, communications authorization, privacy and data protection, and applicable aviation requirements. Any future quantitative claim should identify its source, date, configuration, test conditions, and uncertainty.
